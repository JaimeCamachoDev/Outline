# **Outline**

_**Efecto de contorno para objetos 3D. Genera bordes visibles, ideal para resaltar elementos interactivos o lograr un estilo toon/cómic.**_

</header>

## Requisitos

* Unity **6000.3.10f1**
* Render Pipeline: Universal Render Pipeline (URP)
* Paquetes: Visual Effect Graph

## Contenido

* **VFX Graph:** `Outliner_Sci-Fi`
* **Shader Graph:** `Outline`, `Outliner`, `Outliner_Sci-Fi_Fill`, `Outliner_Sci-Fi_Stroke`, `StrokeEffect_Graph`
* **Sub Graphs:** `ScreenSpaceBayerDithering`, `SpaceFog`
* **Prefabs:** `Outliner_Sci-Fi`
* **Escenas:** `Assets/3-Scenes/Main.unity`, `Assets/3-Scenes/Outline.unity`

## Uso

1. Clona el repositorio y añádelo en Unity Hub (*Add project from disk*).
2. Ábrelo con Unity **6000.3.10f1**.
3. Abre la escena `Assets/3-Scenes/Main.unity` y pulsa **Play**.
